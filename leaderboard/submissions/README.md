# Reviewed community submissions

Open a PR adding **one** `<submission-id>.json` file here. Do not change tooling,
workflow, keys, historical results or documentation in the same submission PR.

Follow [the submission guide](../SUBMIT.md). Passing automated checks makes an
entry eligible for maintainer review. Only a complete benchmark submission with
a current-head approval from a different maintainer can be published after merge.

Pipeline fixtures and demo results belong in tests, never in this directory.
